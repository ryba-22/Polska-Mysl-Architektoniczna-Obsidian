# DevMountJob

Repozytorium dokumentuje trzy poziomy Event Stormingu:

Big Picture → Process Level → Design Level.

Process Level dodaje commands, read models, systems i policies. Design Level proponuje modele wspierające proces.

Projekt używa także CQRS i Event Sourcing, ale sam autor opisuje to jako podejście edukacyjne all-in. Nie należy z niego wyciągać reguły DDD ⇒ CQRS ⇒ Event Sourcing.

## Wartość dla PMA

To dobry case study do porównania discovery z późniejszym wyborem tactical i persistence patterns.
