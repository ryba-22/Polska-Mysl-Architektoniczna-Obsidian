# Software Archetypes

Software Archetype to powtarzalny kształt modelu biznesowego, który pojawia się w wielu domenach pod innym słownictwem.

Nie jest to gotowy framework ani wzorzec implementacyjny. Jest hipotezą strukturalną, którą trzeba dopasować do ubiquitous language konkretnej domeny.
