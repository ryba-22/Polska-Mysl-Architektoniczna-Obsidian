# Memory Resolution Decay

Nie wszystkie wspomnienia wymagają tej samej szczegółowości przez cały czas.

## Model

- świeże zdarzenia zachowują wysoką rozdzielczość;
- starsze informacje są kompresowane do stabilnych decyzji, wzorców i wyjątków;
- istotne fakty mogą zostać utrwalone bezterminowo;
- detale operacyjne naturalnie zanikają.

## PEOS

Pamięć powinna przechowywać przede wszystkim decyzje, invariants, evidence links i unresolved hotspots, a nie pełne transkrypcje każdego runu.
